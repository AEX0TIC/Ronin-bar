### What's new in 0.1.0

The first Ronin Bar: a smart dock across the top of the Windows screen.
- Pinned apps and open windows with their icons
- Working controls: CPU, memory, network, battery and volume
- 80 anime wallpapers from Wallhaven, with previous / next / random and auto-change
- 5 themes that also set Windows' dark or light mode and accent colour
- Installs itself into one folder, starts with Windows, uninstalls cleanly from Settings → Apps
