### What's new in 0.7.1

The launcher shows only the software you use.
- Programs and game launchers from your desktop are added (Steam, Epic, EA, Riot and the like); shortcuts to files, videos, PDFs and folders are not
- Apps that were missing, such as DaVinci Resolve, are found through Windows' list of installed software and their install folder
- Command Prompt, PowerShell, developer prompts and Windows' admin tools (defragment, verifier, event viewer and more) are left out
- The power button is gone from the launcher (it stays on the bar)
- The search hint reads properly (the arrow symbols showed as boxes)
