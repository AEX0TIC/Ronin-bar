### What's new in 0.6.1

Always in sync with Windows.
- Wi-Fi follows Windows' own change reports: scans, connecting, disconnecting, signal
- The connected network is read straight from Windows, so it is always marked correctly
- "searching…" clears as soon as the scan finishes
- The Wi-Fi icon shows connected whenever Windows does; hover it for the network and signal
- Wi-Fi and Bluetooth switches follow changes made in Windows Settings or with the airplane key
- Volume keys show on the bar at once
