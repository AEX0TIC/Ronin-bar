### What's new in 0.5.0

Updates inside the app.
- A "New version available" popup when a new release is out, with Install now and Later
- One click downloads the new version, checks its SHA-256, replaces the old one and restarts the bar; your settings stay
- Turn the popup off, or let new versions install by themselves (Settings → Updates)
- A new README with pictures of the bar and all themes
Note: 0.4 has no updater, so install 0.5.0 by hand once; after that it updates itself.
