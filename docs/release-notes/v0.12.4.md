### What's new in 0.12.4

Wi-Fi switching fixed.
- Turning Wi-Fi back on works again after it was turned off (it could fail with "not in the correct state")
- If Windows' radio switch refuses, Ronin uses the Wi-Fi adapter's own switch, like Windows' Wi-Fi button
- The Wi-Fi switch always shows the adapter's real state
- While Wi-Fi is off, the popup simply says so: no endless "searching…"
