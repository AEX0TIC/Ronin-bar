### What's new in 0.4.0

Ronin's own popups instead of Windows' flyouts, so the whole bar feels like one system.
- Launcher on the Ronin mark: every installed app (Store apps too) with icons, search, pins
- Calendar on the clock, sound popup on the speaker, power menu (lock, sleep, sign out, restart, shut down)
- Battery popup with time left, battery saver and a screen brightness slider
- Wi-Fi popup: networks with signal, connect, disconnect, join with a password
- Quick settings: airplane mode, night light, mobile hotspot, accessibility, project, cast, live captions and more
- Open windows show their real icons, Settings and other Store apps included
- Faster: popups open instantly, sliders and switches react at once
